Thank you for downloading SOFIA!

SOFIA is a lightweight, plug-and-play CLI harness 
designed to bring local AI code refactoring and generation 
directly into your Flutter workflow.

INSTALLATION STEPS
------------------
1. Extract the contents of 'SOFIA-Flutter-Setup.zip'.
2. Run 'SOFIA_Installer.exe'.
3. If Windows SmartScreen displays a security warning:
   - Click "More info".
   - Click "Run anyway".
4. The setup will automatically configure SOFIA in your system PATH 
   and download required background dependencies (Ollama + Qwen 2.5 Coder 7B).

QUICK START
-----------
Open your terminal (CMD, PowerShell, or VS Code terminal) inside 
any Flutter project directory and run:

  sofia -i "Add a custom counter widget" -f "lib/main.dart"

REQUIREMENTS
------------
- Windows 10/11
- Flutter SDK installed and available in system PATH
